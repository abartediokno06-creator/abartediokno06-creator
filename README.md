### 🚀 Current Projects

**ComTrike** — Web-based complaint management system for tricycle commuters in Lipa City. Built with Supabase (PostgreSQL, RLS, Edge Functions), vanilla JavaScript, and Bootstrap 5, deployed on Vercel. Serves both LTO and LGU offices with role-based dashboards, multi-violation submission, and split-jurisdiction routing. Capstone project for De La Salle Lipa's CITE, advised by Rodante S. Chavez.
